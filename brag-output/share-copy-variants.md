## LinkedIn
I've been building Glide, an open-source visual editor for React, Vue, Svelte and Astro.

You click an element in your running app and change it the way you would in a design tool. Glide writes that change to the exact line in your source file. In the video, a color I typed as a hex came out as my Tailwind theme token (text-slate-900 → text-brand-500), and one edit to a cva variant updated every large button.

Under the hood: every write carries a SHA-256 digest of the file, transactions are all-or-nothing, and the server listens on localhost only with a session-token handshake.

183 stars, 505 commits, 408 passing tests, Apache 2.0.

Contributions are welcome: issues, PRs, framework adapters. I'm also open to roles.
